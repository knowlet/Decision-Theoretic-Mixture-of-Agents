# v1.8.0 candidate changelog

Date: 2026-09-21

## Added

- A separate expanded fixture with 128 fit, 64 development, and 200 held-out
  cases for each of BoolQ, OCNLI, CLINC, and TMMLU+.
- Declared English and OOD-Chinese leaderboards before inference.
- A pinned convaiinnovations/laya-multilingual native typed-choice checkpoint.
- Gold-blind 12-shard inference for four native checkpoints.
- Reversed-option and exact-input repeat probes for every dataset.
- Fail-closed analysis for per-dataset and leaderboard-level accuracy,
  calibration, and CPU latency metrics.
- Protocol, registry, adapter, workflow, and contract tests isolated from v1.7.

## Verification status

The implementation currently has no v1.8 Actions result. The latest verified
evidence remains v1.7.0. A v1.8 result can be reported only after the fixture,
all 48 native shards, and the analyzer complete successfully and the artifact
gates pass.

## Interpretation limits

OCNLI is labeled official development data rather than the blind official test.
English checkpoints on OCNLI and TMMLU+ are OOD-Chinese transfer baselines.
Laya multilingual is not a language-only ablation. CPU timings are hosted-runner
measurements, and the leaderboard aggregates do not establish proprietary Jev
equivalence or universal MoA superiority.
