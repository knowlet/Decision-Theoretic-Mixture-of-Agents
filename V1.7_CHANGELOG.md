This release records the first verified Actions run for the requested open
Jev-like models. It is an evaluation extension of the decision-theoretic MoA
project, not a new trained foundation model and not a reproduction of CERA-MoA
co-training.

## Protocol

The native protocol uses the same gold-blind semantic fixture for all three
models: BoolQ, OCNLI, CLINC, and TMMLU+, with 32 fit, 16 development, and 32
held-out test cases per dataset. Inference workers receive the public request
fixture but never `gold.jsonl`. Each model runs 320 primary forwards, 16
reversed-option probes, 8 exact-input repeats, and 12 warmups.

The analyzer checks shard completeness, primary/probe coverage, pinned model and
source revisions, per-file SHA-256 manifests, request digests, probability
simplexes, gold isolation, and zero new API/training activity.

## Reading the result

Decider-2B is the strongest descriptive accuracy/calibration result in this
small cohort. Laya is the fastest on the recorded hosted CPU test cases. The
comparison is limited by the 128 held-out cases per model, the English model
registry, task and language mismatch for OCNLI/TMMLU+, and hosted CPU variance.
The run does not benchmark proprietary Jev, live worker generation, CERA-MoA
training, or production GPU latency.
