# Decision-Theoretic Mixture-of-Agents

A reproducible, finite-support **synthetic decision study** of information acquisition, stopping, verification and preference elicitation.

This repository is being populated with the audited source, tests, reproducible results and revised technical report. It does not benchmark real language models or establish universal architectural optimality.

Research artifacts will be published as a versioned GitHub release after the verification workflow passes. A GitHub technical-report release is not peer review or an arXiv/DOI registration.
