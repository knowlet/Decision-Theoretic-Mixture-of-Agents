## Implementation fixes during validation

- Macro bootstrap draws use independent dataset streams derived from root seed 130918, rather than accidentally sharing an identically seeded generator across datasets. This corrects dependence in the resampling implementation, not the objective or policy outcomes.
- Primary exact-rational normalization was preserved. `audit_transfer.py` adds explicitly post-primary numeric tolerance checks and label-range diagnostics without rewriting observations, labels, or primary results.
